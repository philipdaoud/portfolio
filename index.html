SFTP Neo: a VS Code extension

SFTP Neo keeps a local folder and a remote server in sync over SFTP, FTP or FTPS. It's published on the VS Code Marketplace and Open VSX.

  • Upload on save, two-way sync, and a preview of every change before a sync runs
  • Remote Explorer, a live transfer queue, and versioned backups for rollback
  • Secure by default: OS keychain, SSH agents, jump hosts and host-key checks
  • TypeScript
  • VS Code API
  • SSH / SFTP
  • Security
